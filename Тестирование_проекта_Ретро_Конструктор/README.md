# Тестирование проекта "Ретро конструктор" - Сперанская Анастасия

В этой папке представлен полный цикл тестирования учебного модуля для Битрикс24 под названием "Ретро Конструктор". Все работы выполнены в рамках учебного курса Битрикс24.Университет.  

- **1. Анализ требований:** Этап изучения продукта, анализ концепции, MVP, анализ требований и рисков;
- **2. Тест-план проекта:** Этап планирования дальнейшего тестирования, определение целей, границ, этапов работы. Распределение задач между двумя тестировщиками;
- **3. Чек-листы и тест-кейсы:** Содержит чек-листы и тест-кейсы по всем блокам, за которые я была ответственна в рамках проекта;
- **4. Баг-репорты:** Некоторые баг-репорты, оформленные по найденным багам.

В рамках обучения были изучены основы автоматизированного тестирования, были созданы автотесты на С# с использованием Selenium на фреймворке Битрикс24, но исходный код не может быть включён в открытое портфолио из-за технических ограничений среды.

По итогам проекта было разработано 5 чек-листов на 187 проверок, 38 тест-кейсов, оформлено 12 баг-репортов, написано 4 автотеста.
