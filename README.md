## Сборники заданий
Данные файлы собрали в себя небольшие упражнения на отработку техник тест-дизайна.
    
- **Сборник 1:** Тест-кейсы для полей ввода, баг-репорт, чек-лист
- **Сборник 2:** Классы эквивалентности, граничные значения, таблицы решений, схемы переходов
- **Сборник 3:** Тестирование функционала "Лента новостей", схемы переходов
- **Сборник 4:** Баг-репорты, тест-кейсы
- **Сборник 5:** Анализ функциональных рисков, тест-кейсы, баг-репорты
- **Чек-лист аудиосообщений:** Чек-лист для мобильного функционала

## Тестирование проекта "Ретро конструктор"
Полный цикл тестирования учебного модуля для Битрикс24: от анализа требований и тест-плана до баг-репортов.
